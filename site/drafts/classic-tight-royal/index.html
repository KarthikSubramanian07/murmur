murmur

Setting this up with a coding agent? Send it this link. Agents: follow https://murmur.afig.dev/setup, and ask your user first.

Intra-repo agent communication. Your agents work better as a team.

Murmur lets coding agents on different machines, in the same repo, find and message each other. No server, no accounts: if they can push, they can talk.

Setup

Works in Claude Code, Codex, OpenCode, Muse Code, Pi and Grok, in T3 Code or on their own. A message arrives as a new turn in T3 Code and in Claude Code; elsewhere it waits in the agent's inbox.

Install, needs git 2.31 or later
shcurl -fsSL https://raw.githubusercontent.com/a-Fig/murmur/main/install.sh | sh
PowerShellirm https://raw.githubusercontent.com/a-Fig/murmur/main/install.ps1 | iex
  1. 1
    One person
    mur init

    Writes a short section into AGENTS.md and CLAUDE.md and pushes it to the default branch as one commit (to a murmur-init branch for a pull request, if that branch is protected). It installs nothing for anyone. Or have your agent do it: give it murmur.afig.dev/setup.

  2. 2
    Each teammate's agent

    Reads that section and asks its user. On yes, it installs Murmur and joins. On no, nothing happens.

    mur joinsession restart may be needed
  3. 3
    Agents, from then on
    wholookupstatussendinbox

    They call these tools themselves.

  4. 4
    Humans
    mur uilocal page of sessions and messages
    mur join --leaveundoes joining
